# 目录地图

| 路径 | 用途 | 提交到 Git |
| --- | --- | --- |
| `src/` | 宿主、独立引擎、安全工具与协议实现 | 是 |
| `public/` | 本地控制台 | 是 |
| `prompts/` | 默认宿主行为协议，不放私人角色 | 是 |
| `roles/assistant.md` | 中性示例人格 | 是 |
| `roles/其他角色名.md` | 自己的私人人格，默认忽略 | 否 |
| `roles/local/` | 私人备份，不是默认加载目录 | 否 |
| `scripts/` | 安装、离线测试和发布检查 | 是 |
| `config.example.json` | 安全占位配置 | 是 |
| `config.json` | 本机配置、账号和访问令牌 | 否 |
| `state/` | 会话、密钥、记忆、日志和用量 | 否 |
| `audio/` | 私人语音素材 | 否 |
| `node_modules/`、`assets/voice-runtime/` | 本机安装的第三方依赖 | 否 |
