- 默认离线回归：27/27 个脚本通过，涵盖独立进程、模型设置、安全工具注册、会话重放、人格、记忆、群权限和控制台。

- 发布检查和私密数据比对通过；实际账号、访问令牌、密钥、聊天内容及私人人格均未进入公开源码。
- 本机运行更新经过备份和选定文件补丁校验；配置、秘密文件、人格、提示词保持不变，本地会话映射及聊天记忆保留。只读检查确认独立引擎就绪、网关连接和账号在线，移除的旧后端接口返回 404。

## 验证边界

测试使用临时目录、虚构凭据、模拟模型与 QQ 网关；浏览器只能访问隔离服务。线上检查只读取状态，不发送群聊 / 私聊测试消息，不调用付费模型或 TTS。

外置旧 `voice-tool` 不在本源码范围内，相关检查明确跳过，不计为通过。离线检查无法验证在线服务额度、模型效果、真实群发送权限或语音音质。

DSH 不再属于可选运行后端，因此不再保留它的安装 / 插件兼容测试；取而代之的是独立进程对模拟旧后端零请求、无凭据探测和无特权工具的验证。每次发布仍需核对对应 GitHub Actions 提交的检查结果。
