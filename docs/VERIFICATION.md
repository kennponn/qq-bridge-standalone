## 验证边界

测试使用临时目录、虚构凭据、模拟模型与 QQ 网关；浏览器只能访问隔离服务。线上检查只读取状态，不发送群聊 / 私聊测试消息，不调用付费模型或 TTS。

外置旧 `voice-tool` 不在本源码范围内，相关检查明确跳过，不计为通过。离线检查无法验证在线服务额度、模型效果、真实群发送权限或语音音质。

安全测试还检查进程隔离、凭据读取边界和工具权限。每次发布仍需核对对应 GitHub Actions 提交的检查结果。

维护后的运行检查应分别确认模型配置就绪、网关连接、QQ 账号在线，以及 AI 暂停状态。前三项通过不代表机器人正在回复；暂停状态会跨重启保留，维护结束后应按维护前的状态恢复并核对。
