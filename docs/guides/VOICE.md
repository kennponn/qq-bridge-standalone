# 独立引擎的 QQ 语音功能

内置控制台 `http://127.0.0.1:3100/` 提供语音设置、微软 Edge／小米 MiMo 切换、音色与语速选择、文本合成试听，以及向现有群聊或私聊明确发送的操作。不需要单独安装旧 `voice-tool` 图形界面。

## 接收语音与转写

`socialV2.voice.incoming.enabled` 默认开启。SnowLuma 原生的 `fetch_ptt_text` 操作根据真实 QQ 消息 ID 转写语音，使用 QQ 在线服务，不是离线识别，也不需要新增第三方模型密钥。QQ 转写可能需要约 20 秒，宿主默认在 22 秒后停止等待。只有当前会话等待，其他会话和普通文本处理互不影响。

转写保留真实发送者、提及和引用来源。识别出的语音不能执行宿主斜杠命令、批准请求或直接创建明确的长期事实。转写失败时只显示诚实的占位说明，不猜测内容。暂停、重置、权限和人格变化会使旧任务失效。

## 文本转语音与试听

TTS 默认关闭，`onlineConsent` 默认 `false`。在控制台语音区域启用朗读，明确同意将朗读文本发送给 Microsoft 在线服务，选择音色并保存。该服务不需要 API Key，但需要网络，其稳定性不由本项目保证。

试听只上传输入的合成文本，不发送 QQ 消息，也不会自动播放。真实发送是独立操作，需要另外确认。“允许 AI 发语音”开关与在线朗读分开；允许后，下一模型回合可使用绑定会话的 `qq_speak_text` 工具。它沿用管理员选择的音色，只接收短纯文本，不接收路径、网址、SSML 或命令。默认不自动朗读回复，也不会因此改变当前人格或模型。

## 可设置的随机语音回复

在控制台“语音识别与在线朗读”内设置“随机语音回复概率 %”，填写 **0–100 的整数**后保存。`0%` 关闭随机转换（默认）；`20%` 表示每次符合条件的发送独立抽取，约五次中有一次命中，但不保证固定次数；`100%` 表示符合条件的回复均尝试转换。

- 必须同时允许 AI 发语音、启用在线朗读并同意在线服务；关闭 AI 权限不会影响管理员手动试听或发送。
- 只对二代仿真的单条短纯文本回复抽一次，包括群聊、私聊及旧文本工具的兼容入口。引用、@、链接、代码、CQ 富内容、超过 TTS 字数上限及连发多条保留文字；明确语音工具不再次抽取。
- 命中后使用已保存的声线和语速，只提交一条语音，不再发重复文字。括号内动作与内心对白沿用文字发送的过滤规则，不会被意外朗读。
- 语音额度用尽或合成在提交前失败，可回退原文字。已开始向 QQ 提交后，即使超时或送达未确认，也不补发文字或自动重试。
- 在线服务同意、概率、人格、令牌、暂停或会话权限在处理中变化，会取消在途回复。限频、白名单、群禁言和内容审查继续生效。
- 不新增定时主动发言；只转换原本要发送的正常回复。模型显式调用语音工具不属于此概率统计，`0%` 不等于关闭所有 AI 语音工具。

对应配置为 `socialV2.voice.tts.randomReplyProbability`（百分数，不是 0–1 小数）。开源示例默认不启用随机转换；管理员可以在页面保存后即时生效，无需每次重启。

## 小米 MiMo 语音

1. 在 [小米官方开放平台](https://platform.xiaomimimo.com/) 创建 API Key。
2. 在控制台选择“小米 MiMo”，输入独立 Key，选择音色，明确同意向小米提交朗读文字和风格描述后保存。
3. 点击“生成试听（不发 QQ）”；确认效果后再开启 AI 语音或手动选择会话发送。

固定模型为 `mimo-v2.5-tts`，固定地址为 `https://api.xiaomimimo.com/v1/chat/completions`，不允许模型或用户消息更换服务地址。支持八种预置音色；默认中文女声“冰糖”。可选风格描述最多 200 字；语速百分比会转换为模型风格提示，不保证精确倍速。目前只接预置音色，不接音色设计、复刻或流式 QQ 发送。

MiMo 不启动 Python，不在本机运行语音大模型；FFprobe 和 QQ 网关的音频校验／转换仍然需要。服务失败不会自动把文字上传到另一个供应商。改变供应商需重新同意；已有试听失效，正在合成的旧供应商结果会丢弃。

Key 保存在 `state/mimo-tts-secret.json`，写入前限制文件权限，独立于聊天模型密钥；API 只返回是否配置，不返回 Key。本机状态文件不是便携加密文件，请勿上传、分享或放进开源压缩包。可用 `MIMO_API_KEY` 环境变量覆盖；存在该变量时，控制台不能替换／清除实际生效的环境变量 Key，需先移除变量。不要把 Key 写入 `config.json`、人格或风格描述。

健康状态只确认本机 Key 可读；账号权限、额度与网络可用性以实际试听为准。费用和免费活动以 [小米官方定价](https://mimo.mi.com/docs/zh-CN/price/pay-as-you-go) 为准，不承诺永久免费。

微软 Edge 组件需要 Python 和 FFprobe。将锁定版本的 Python 依赖安装到桥接器目录，而不是全局环境：

```powershell
python -m pip install --target assets/voice-runtime/vendor -r scripts/requirements-voice.txt
```

控制台报告组件就绪时只检查本地模块能否导入，健康检查不会合成文本或请求在线语音提供方。合成文本限制为 300 字符，生成 MP3 会检查大小和时长，最长 90 秒；文件使用不透明 ID 缓存 10 分钟。最多同时运行两个合成进程，并保留 20 条试听。过期生成文件在下一次合成时清理；关闭桥接器不会删除管理员的语音素材库。缓存路径和工作进程环境均隔离。

## 发送权限与送达验证

AI 语音遵守会话令牌、当前白名单、暂停和静默状态、人格变化、QQ 群发送权限以及现有语音限制，默认每会话每分钟 2 条、每小时 10 条。管理员手动发送也须通过白名单、内容审查和语音额度限制。已知凭据和路径格式在文本传给在线服务前会被拦截。

只有回读已发送的 QQ 消息并确认含有语音片段，才能返回 `verified=true`。收到发送响应但未验证，不等于确认送达；不要自动重试未确认的消息，因为 QQ 可能已经接收。已有音频文件仍可通过现有语音素材库接口使用。
