# 发布隐私检查

使用 `npm run release:check`，或兼容入口 `node scripts/privacy-scan.mjs`。

扫描器优先检查 Git 已跟踪文件及未忽略的候选文件；没有 Git 仓库时遍历源码。即使 `config.json` 或 `state/` 被写进忽略规则，只要已被 Git 跟踪仍会报错。

检查包括：私有配置和运行目录、备份、二进制组件、本机用户路径、常见密钥格式、凭据字面量、示例配置安全默认值和重复 JSON 键。发现问题只输出文件、行号和规则，不回显值。

测试中的少数明确标识为 synthetic / fixture 的字符串，以及不带任何密钥正文的测试私钥头允许作为夹具；整个测试文件并不免检。

扫描器不是秘密识别的完备保证。普通数字、自然语言中的私人信息、不常见的密钥格式和第三方内容授权仍需要人工检查。公开前审阅 staged diff，不要复制整个运行目录，也不要沿用未经审查的旧提交历史。

如果需要针对自己的真实 QQ、群号或额外秘密增加检查，请扩展扫描器并使用本地私有配置；不要将真实值写进公开扫描规则。旧版本 `privacy-rules.json` 的宽松白名单不是这个严格检查器的放行依据。

真实密钥一旦公开，应首先撤销或轮换。删除文件、重写历史或删除 GitHub 仓库都不能保证撤回已有复制品。
