# 安全基线

## 权限边界

- 只运行独立引擎。模型没有 Shell、任意本地文件读写、插件安装或跨会话控制能力。
- QQ 目标和工具令牌由宿主绑定，模型不可改写。白名单默认拒绝，群禁言、暂停、静默、工具开关和配额在发送前再次验证。
- 控制台仅监听回环地址，写操作校验 JSON 与同源；可选本机免令牌模式不向局域网开放。带智能体标记但无有效会话令牌的请求始终拒绝。
- 人格、群聊、转写及引用内容不授予管理权限。语音转写只作为带来源的对话内容，不进入管理员命令解析。
- 重置、撤销会话或修改人格会取消旧回合；旧令牌与迟到发送不能复活。

## 密钥与数据

- 模型密钥、MiMo 密钥、网关令牌和控制台令牌分开保存；模型密钥绑定提供方与地址，空值保存不清除。
- 私密文件使用原子替换并限制 ACL。ACL 不是加密，也无法防御已控制本机管理员账号的程序。
- 日志、记忆、角色和语音缓存不入库。源码发布检查仅是辅助，发布前还应人工核对差异。
- 模型和搜索只使用各自明确配置的凭据，不探测其他程序的秘密文件。

## 网络与语音

模型请求仅支持 HTTPS，拒绝含凭据、查询参数或片段的 API 基础地址；搜索与媒体读取继续使用 SSRF 防护与体积上限。输入仍可能被第三方服务保留，请取得参与者同意。

在线语音需明确同意。发送前校验音频、群权限、配额和回合有效性。随机语音过短时在发送前退回文字；发送结果不确定时不自动重发。

QQ 与 SnowLuma 属于外部软件，本项目不控制其原生实现、账号风控或许可。不要把 OneBot 接口暴露到公网。

## 验证

运行 `npm test`、`npm run test:voice`、`npm run test:snowluma-launcher` 和 `npm run release:check`。均使用离线夹具，不应发送真实 QQ 消息或调用付费模型。
