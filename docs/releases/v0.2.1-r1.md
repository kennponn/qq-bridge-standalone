# v0.2.1-r1：首个开源预发布版

发布日期：2026-11-04。

这是 QQ Bridge Standalone 开源分支的第一个带版本标签的发布快照，版本号为 `0.2.1-r1`。

## 主要内容

- 默认使用 Standalone 独立引擎，连接 OpenAI 兼容模型和自行安装的 QQ / OneBot 网关。
- 提供本地网页控制台、白名单、人格与会话管理，以及记忆、图片、搜索和可选语音功能。
- 发布经过整理的源码、安全配置示例、中性示例人格和中文使用文档。
- 新增中文更新日志和版本一致性检查；以后每次发布都有独立的版本、日期和说明。
- 保留原作者版权及 MIT 许可证原文，另列第三方依赖许可说明。

## 安装与升级

需要 Node.js >= 22.13.0。下载并解压本版本源码后，按 [README](../../README.md) 安装依赖、配置模型和网关。

已有用户升级前应停止机器人，并私下备份自己的配置、角色和会话状态。只同步公开源码，不要用示例配置覆盖正在使用的 `config.json`，也不要把运行目录或备份上传到 GitHub。

## 验证与限制

本版本使用离线回归、语音专项、发布隐私扫描和版本文档检查，不调用真实 QQ 或付费模型。线上网关、模型和语音服务需要使用者另行验证。

这是预发布版。源码不包含可用 Token、私人配置、聊天记录、QQ 客户端或网关二进制；Standalone 不提供任意命令执行和本地文件访问。
