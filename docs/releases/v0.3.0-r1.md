# v0.3.0-r1：模块化控制台与 MiMo 语音

发布日期：2026-11-05。

本次是相对 `v0.2.1-r1` 的功能更新，继续作为预发布版提供；旧版标签与下载保留不动。

## 控制台更易用

- **二代仿真分成六个模块**：运行总览、唤醒节奏、回复工具、语音设置、记忆提示词、日志反馈。切换保留输入；顶部和底部「保存全部参数」仍包含隐藏模块。
- **人格管理分成三个页签**：人格库、编辑人格、高级设置。人格库支持名称搜索、每页四张卡片；点击卡片只载入编辑，不会自动切换当前人格。
- **草稿保护**：载入其他人格或清空编辑前确认未保存修改；迟到的读取结果不会覆盖新输入。切换页签保留草稿，但刷新／关闭页面不会恢复未保存正文。
- **可读性改进**：加深下拉框边界、折叠标题和选中状态，增大表单字号；支持浅色／深色主题、键盘操作和手机窄屏。全局搜索可跳到隐藏模块。

## MiMo 与随机语音

- 接入小米官方 `mimo-v2.5-tts`，提供八种预置音色、语速和可选风格描述；保留微软 Edge。MiMo 使用 Node HTTPS，不启动 Python；音频校验仍需要 FFprobe。
- 增加「允许 AI 发语音」和 0–100% 随机语音概率。只有符合条件的单条纯文本回复参与随机转换；引用、点名、富文本及多条连发保持文字。
- 修复通用保存漏存语音设置；Key 留空保留已保存值，清除必须确认。MiMo Key 独立保存在本机受限文件，不回传、不复用聊天模型 Token。
- 自动回复有效正文不足 4 字符时保持文字；自动生成的音频不足 1.5 秒时在交给 QQ 前退回原文字，不灌静音凑时长。不影响手动试听／发送。
- 降低音频处理子进程优先级、限制 FFmpeg 线程，减少桌面资源竞争；保留权限、配额、取消和防重复发送检查。
- 修复 SnowLuma 启动记录未截断旧内容导致的保存错误。

## 安装与升级

需要 Node.js >= 22.13.0，QQ／OneBot 网关由使用者自行安装。详见 [README](../../README.md)。

1. 升级前保存控制台草稿，停止桥接，并私下备份配置、角色、提示词和会话状态；不要上传这些备份。
2. 下载本版本源码，仅更新公开代码。不要用示例文件覆盖自己的 `config.json`、`roles/`、`prompts/` 或 `state/`；尤其保留 `state/mimo-tts-secret.json`。
3. 在更新后的源码目录运行 `npm ci`，启动桥接，然后刷新控制台。若使用 Edge，另按语音文档安装 Python 依赖；MiMo 不需要这一步。
4. 先检查连接状态、当前人格和语音参数，再自行试听验证。公开默认配置仍关闭在线朗读、在线服务同意项与随机语音；本版本不替使用者授权或开启这些功能。

## 验证与边界

- 更新兼容范围内的 npm 依赖锁定版本，发布时 `npm audit` 为 0 项告警；这不保证不存在未知漏洞。升级需要执行 `npm ci`，不能只复制网页文件。
- 发布检查覆盖离线回归、语音专项、启动器、版本一致性和隐私扫描，不向真实 QQ 发送测试消息，不调用付费模型。
- 控制台专项浏览器检查覆盖模块切换、搜索／分页、草稿、保存、浅色／深色及 320–1440 像素布局。
- 完整旧版浏览器套件仍有历史载荷基线、未模拟接口和用量趋势时序问题，不计为本次全部通过的测试；线上网关、模型和 QQ 语音播放仍需各环境验证。
- 群聊禁言、白名单、暂停和频率限制仍然生效；短音频回退不代表所有 QQ 客户端的播放问题已解决。
- 下载包仅含公开源码，不含私人配置、聊天记录、私人角色、密钥、QQ／SnowLuma 二进制或已安装依赖。附件提供 SHA-256 校验文件。
