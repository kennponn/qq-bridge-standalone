# v0.4.0-r1 — 纯独立版

发布日期：2026-11-05。

这是一次不向后兼容的预发布更新：不再支持 DSH 后端，而非默认关闭或隐藏入口。

## 主要变化

- 删除旧 API 客户端、插件、预设安装、事件流、远程会话、审批及完整本地 Agent。
- 保留 QQ / SnowLuma 网关、模型直连、人格卡、聊天记忆、图片表情、会话安全工具和 MiMo / Edge 语音。
- 控制台不再选择后端或仿真代次；原有模块页签、人格分页、高对比度控件及手机布局继续保留。
- 模型与搜索不再读取旧后端凭据。已有独立模型 Key 留空保存仍保留；MiMo Key 与语音概率、配额不重置。
- 本地系统提示词保存、备份及还原无需重新安装预设；旧会话文件不自动删除。

## 升级

先停止旧后端任务并备份私人配置、角色、提示词和状态。已有独立版用户保留这些本机文件；旧后端用户需在模型面板明确配置独立模型，不会自动迁移旧凭据。具体步骤见 [独立引擎与迁移说明](../guides/STANDALONE.md)。

## 验证范围

离线测试覆盖独立进程、实际安全工具注册、会话重放、人格、记忆、语音、群权限和本地控制台；测试不发送真实 QQ 消息，不调用付费模型。在线网关、提供方额度及音色效果仍需使用者自行确认。
