# v0.4.0-r1 — 纯独立版

发布日期：2026-11-05。

本次预发布采用单一独立引擎架构，由本地桥接器统一管理模型调用、会话和安全工具。架构调整包含不向后兼容的变更，更新前请备份私人数据。

## 主要变化

- 统一模型请求与会话调度，精简依赖和安装步骤。
- 支持 QQ / SnowLuma 网关、模型直连、人格卡、聊天记忆、图片表情、会话安全工具和 MiMo / Edge 语音。
- 简化控制台设置，保留模块页签、人格分页、高对比度控件及手机布局。
- 模型与搜索分别使用明确配置的凭据。模型 Key 留空保存仍保留；MiMo Key 与语音概率、配额不重置。
- 系统提示词可在本地保存、备份及还原，下一回合生效；已有会话数据不会因更新自动清除。

## 升级

停止桥接及守护进程，备份私人配置、角色、提示词和状态。只更新公开源码及依赖，不要用示例配置覆盖本机文件。启动后分别核对模型、网关、账号和 AI 暂停状态。具体步骤见 [独立引擎与更新说明](../guides/STANDALONE.md)。

## 验证范围

离线测试覆盖独立进程、实际安全工具注册、会话重放、人格、记忆、语音、群权限和本地控制台；测试不发送真实 QQ 消息，不调用付费模型。在线网关、提供方额度及音色效果仍需使用者自行确认。
