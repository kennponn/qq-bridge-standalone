# 人格卡

每个角色使用一个 Markdown 文件，文件名是角色名。`assistant.md` 是全新编写、可随项目分发的中性示例。

在本地控制台「人格与角色」中选择或保存人格。人格只描述身份、性格和表达风格；工具协议由宿主注入，不要在卡片中复制工具调用、授权、管理命令或解除安全限制的指令。

私人卡片放在本目录并使用自己的文件名，如 `roles/my-assistant.md`。除 README 和 `assistant.md` 示例外，新建的角色 Markdown 默认被 Git 忽略。`roles/local/` 可作私人备份，但不是默认加载目录。不要用私人内容覆盖已跟踪的示例，发布前仍应运行 `npm run release:check`，也不要复制未经授权的第三方人设。

需要按运行模式区分内容时，可使用 `## 标题 〔一代〕` 或 `## 标题 〔二代〕`；未标记的章节用于两种模式。Standalone 只支持二代仿真。
